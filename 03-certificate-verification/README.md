# โจทย์ที่ 3 ระบบออกและตรวจสอบใบรับรองดิจิทัล

Blockchain Digital Certificate Verification System

## สถานการณ์ทางธุรกิจ (Business Scenario)

บริษัท SkillTrust Academy เป็นผู้ให้บริการฝึกอบรมบุคลากรด้านเทคโนโลยีสารสนเทศ เช่น AI, Cybersecurity, Cloud Computing และ Data Analytics โดยในแต่ละปีมีผู้เข้ารับการอบรมจำนวนมาก บริษัทออกใบรับรองในรูปแบบ PDF แต่พบว่ามีบุคคลนำใบรับรองไปแก้ไขชื่อหรือรายละเอียด รวมทั้งผู้ว่าจ้างไม่สามารถตรวจสอบได้ทันทีว่าใบรับรองเป็นของแท้หรือยังมีผลใช้งานอยู่

บริษัทจึงต้องการพัฒนาระบบออกใบรับรองดิจิทัลโดยใช้ Ethereum Smart Contract เพื่อบันทึกหลักฐานการออกใบรับรองให้ตรวจสอบได้อย่างน่าเชื่อถือ

## ฟังก์ชันที่ต้องการ (Functional Requirements)

1. ลงทะเบียนหลักสูตร (Create Training Course) ผู้ดูแลระบบสร้างหลักสูตร รหัสหลักสูตร และรายละเอียดการอบรม
2. ออกใบรับรอง (Issue Certificate) ผู้ที่ได้รับสิทธิ์สามารถออกใบรับรองพร้อมรหัสอ้างอิง วันที่ออก และข้อมูลผู้รับใบรับรอง
3. บันทึกหลักฐานบน Blockchain (Store Certificate Hash) บันทึก Hash ของใบรับรองเพื่อใช้ยืนยันว่าเอกสารไม่ถูกแก้ไข
4. ตรวจสอบความถูกต้อง (Verify Certificate) ผู้ใช้งานสามารถค้นหาด้วยรหัสใบรับรองหรือสแกน QR Code เพื่อตรวจสอบสถานะ
5. เพิกถอนใบรับรอง (Revoke Certificate) ผู้ดูแลระบบที่ได้รับสิทธิ์สามารถยกเลิกใบรับรองที่ออกผิดพลาดหรือมีการทุจริต โดยยังคงประวัติการออกไว้
6. แสดงประวัติใบรับรอง (Certificate Dashboard) ผู้เข้าอบรมสามารถเชื่อมต่อ Wallet เพื่อดูรายการใบรับรองที่ผูกกับบัญชีของตน

**กฎทางธุรกิจสำคัญ:** ใบรับรองแต่ละใบต้องมีรหัสไม่ซ้ำกัน ผู้ที่ไม่ได้รับอนุญาตห้ามออกหรือเพิกถอนใบรับรอง และไม่ควรนำข้อมูลส่วนบุคคลขึ้น Public Blockchain โดยตรง

**ผลลัพธ์ที่คาดหวัง:** ระบบตรวจสอบใบรับรองออนไลน์ที่ช่วยป้องกันการปลอมแปลงเอกสาร และลดขั้นตอนการตรวจสอบคุณวุฒิของผู้สมัครงาน
