# โจทย์ที่ 4 ระบบจัดการสัญญาเช่าอสังหาริมทรัพย์และเงินประกัน

Smart Property Rental & Deposit Management

## สถานการณ์ทางธุรกิจ (Business Scenario)

บริษัท SmartLiving Property ให้บริการบริหารจัดการห้องพักและอพาร์ตเมนต์ให้เช่ากว่า 200 ห้อง โดยบริษัทพบปัญหาการจัดเก็บเงินประกัน ความไม่ชัดเจนของเงื่อนไขการคืนเงิน และข้อโต้แย้งระหว่างเจ้าของห้องกับผู้เช่าเมื่อสิ้นสุดสัญญา

บริษัทต้องการพัฒนาระบบบริหารสัญญาเช่าผ่าน Blockchain เพื่อให้ผู้เช่าและเจ้าของห้องตรวจสอบเงื่อนไขที่ตกลงร่วมกัน และใช้ Smart Contract ควบคุมเงินประกันตามสถานะสัญญา

## ฟังก์ชันที่ต้องการ (Functional Requirements)

1. ลงทะเบียนทรัพย์สิน (Register Property) เจ้าของห้องสามารถสร้างรายการห้องเช่า ค่าเช่า และเงินประกัน
2. สร้างสัญญาเช่า (Create Rental Agreement) ระบุคู่สัญญา วันเริ่มต้น วันสิ้นสุด และเงื่อนไขสำคัญ
3. ยืนยันสัญญา (Confirm Agreement) ผู้เช่าและเจ้าของห้องยืนยันการยอมรับเงื่อนไขด้วย Wallet ของตน
4. ฝากเงินประกัน (Deposit Security) ผู้เช่าโอนเงินประกันในรูปแบบ ETH เข้าสู่ Smart Contract
5. บันทึกค่าเช่า (Record Rental Payment) ผู้เช่าชำระค่าเช่าและตรวจสอบประวัติธุรกรรมของแต่ละงวด
6. คืนเงินประกัน (Refund Deposit) เมื่อสิ้นสุดสัญญาและผ่านการตรวจสภาพห้อง ระบบคืนเงินตามยอดที่ได้รับอนุมัติ
7. จัดการข้อโต้แย้ง (Rental Dispute) กรณีมีข้อพิพาทเกี่ยวกับความเสียหาย ให้ผู้มีอำนาจที่กำหนดไว้พิจารณาและบันทึกผลก่อนปล่อยเงิน

**กฎทางธุรกิจสำคัญ:** การหักเงินประกันต้องมีเหตุผลและการอนุมัติตามเงื่อนไขที่ตกลงกัน และต้องไม่สามารถคืนเงินเกินยอดคงเหลือของเงินประกัน

**ผลลัพธ์ที่คาดหวัง:** ระบบบริหารสัญญาเช่าที่ช่วยให้การจัดการเงินประกันโปร่งใส ลดข้อพิพาท และสามารถตรวจสอบประวัติธุรกรรมย้อนหลังได้
