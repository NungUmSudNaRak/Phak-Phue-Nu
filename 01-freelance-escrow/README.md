# โจทย์ที่ 1 ระบบจ้างงานฟรีแลนซ์และชำระเงินตามผลงาน

Freelance Escrow & Smart Payment Platform

## สถานการณ์ทางธุรกิจ (Business Scenario)

บริษัท DigitalWork Solutions เป็นแพลตฟอร์มตัวกลางสำหรับจับคู่ผู้ว่าจ้างกับฟรีแลนซ์ที่รับพัฒนาเว็บไซต์ แอปพลิเคชัน และออกแบบกราฟิก โดยพบปัญหาว่าผู้ว่าจ้างบางรายไม่ชำระเงินหลังได้รับงาน ขณะที่ฟรีแลนซ์บางรายไม่ส่งมอบงานตามข้อตกลง ส่งผลให้ทั้งสองฝ่ายขาดความเชื่อมั่นในการทำธุรกรรม

บริษัทจึงต้องการพัฒนาแพลตฟอร์มที่ใช้ Smart Contract บน Ethereum เพื่อทำหน้าที่เป็นตัวกลางเก็บเงิน (Escrow) และควบคุมการจ่ายเงินโดยอัตโนมัติเมื่อผู้ว่าจ้างยืนยันการรับมอบงาน

## ฟังก์ชันที่ต้องการ (Functional Requirements)

1. สร้างข้อตกลงการจ้างงาน (Create Contract) ผู้ว่าจ้างสามารถระบุชื่อโครงการ รายละเอียดงาน ค่าจ้าง กำหนดส่ง และ Wallet Address ของฟรีแลนซ์
2. ฝากเงินค่าจ้าง (Deposit Payment) ผู้ว่าจ้างโอน ETH เข้าสู่ Smart Contract เพื่อเป็นหลักประกันการชำระเงิน
3. บันทึกการส่งมอบงาน (Submit Work) ฟรีแลนซ์บันทึกหลักฐานการส่งมอบงาน เช่น URL หรือ Hash ของไฟล์ผลงาน
4. อนุมัติและจ่ายเงิน (Approve & Release Payment) ผู้ว่าจ้างตรวจรับงานและยืนยันการอนุมัติ ระบบจึงโอน ETH ให้ฟรีแลนซ์โดยอัตโนมัติ
5. จัดการข้อพิพาท (Dispute Management) คู่สัญญาสามารถแจ้งข้อพิพาท และให้ผู้ดูแลที่ได้รับสิทธิ์พิจารณาคืนเงินหรือจ่ายเงินตามเงื่อนไข
6. ติดตามสถานะธุรกรรม (Transaction Tracking) ผู้ใช้งานตรวจสอบสถานะการจ้างงาน ประวัติการชำระเงิน และ Transaction Hash ผ่านหน้าเว็บได้

**กฎทางธุรกิจสำคัญ:** ห้ามจ่ายเงินซ้ำ และต้องไม่สามารถเบิกเงินออกจาก Escrow ได้หากยังไม่เข้าเงื่อนไขการอนุมัติหรือการระงับข้อพิพาท

**ผลลัพธ์ที่คาดหวัง:** ระบบจ้างงานออนไลน์ที่ลดความเสี่ยงการไม่ชำระเงิน และสร้างความเชื่อมั่นให้ผู้ว่าจ้างและผู้รับจ้าง
