# โจทย์ที่ 2 ระบบตรวจสอบย้อนกลับสินค้าเกษตรปลอดภัย

Blockchain Agricultural Product Traceability

## สถานการณ์ทางธุรกิจ (Business Scenario)

บริษัท GreenFarm Supply Chain ดำเนินธุรกิจจัดจำหน่ายผักและผลไม้ปลอดภัยให้กับซูเปอร์มาร์เก็ตและร้านอาหาร โดยรับสินค้าจากเกษตรกรหลายพื้นที่ ผ่านศูนย์คัดแยกและบริษัทขนส่งก่อนถึงผู้จำหน่าย ปัจจุบันข้อมูลการผลิต การขนส่ง และการรับสินค้าอยู่คนละระบบ ทำให้ตรวจสอบแหล่งที่มาของสินค้าได้ยาก เมื่อพบสินค้าที่มีปัญหา บริษัทไม่สามารถระบุล็อตที่ได้รับผลกระทบได้รวดเร็ว

บริษัทจึงต้องการพัฒนาระบบ Blockchain สำหรับบันทึกประวัติสินค้าในแต่ละขั้นตอน เพื่อให้ข้อมูลตรวจสอบย้อนหลังได้และลดความเสี่ยงจากการแก้ไขประวัติโดยไม่ได้รับอนุญาต

## ฟังก์ชันที่ต้องการ (Functional Requirements)

1. ลงทะเบียนผู้เกี่ยวข้อง (Register Stakeholders) กำหนดสิทธิ์ของเกษตรกร ผู้ขนส่ง ผู้จัดจำหน่าย และผู้ดูแลระบบ
2. ลงทะเบียนสินค้า (Register Product Batch) เกษตรกรบันทึกรหัสล็อต ชื่อสินค้า วันที่เก็บเกี่ยว แหล่งผลิต และข้อมูลการรับรอง
3. บันทึกการส่งต่อสินค้า (Transfer Ownership/Custody) ผู้เกี่ยวข้องบันทึกการส่งมอบและรับสินค้าในแต่ละขั้นตอน
4. อัปเดตสถานะสินค้า (Update Product Status) เปลี่ยนสถานะ เช่น เก็บเกี่ยวแล้ว อยู่ระหว่างขนส่ง ถึงคลังสินค้า หรือส่งถึงร้านค้า
5. ตรวจสอบย้อนกลับ (Trace Product History) ผู้บริโภคสแกน QR Code เพื่อดูแหล่งผลิตและประวัติการเดินทางของสินค้า
6. แจ้งเตือนล็อตสินค้าที่มีปัญหา (Product Recall) ผู้ที่ได้รับสิทธิ์สามารถระบุล็อตที่ต้องเรียกคืน พร้อมบันทึกเหตุผลและสถานะ

**กฎทางธุรกิจสำคัญ:** การเปลี่ยนผู้ครอบครองสินค้าต้องได้รับการยืนยันจากผู้ที่มีสิทธิ์ และประวัติการส่งมอบเดิมต้องตรวจสอบย้อนหลังได้

**ผลลัพธ์ที่คาดหวัง:** ระบบตรวจสอบย้อนกลับสินค้าเกษตรที่เพิ่มความโปร่งใส ช่วยจัดการการเรียกคืนสินค้า และสร้างความเชื่อมั่นให้ผู้บริโภค
